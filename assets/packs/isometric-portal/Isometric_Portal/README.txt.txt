# Isometric Forest Tileset (Free)

Thank you for downloading this isometric pixel art asset pack! 

## Specs:
- Tile Grid Size: 32x32 px (Isometric 2:1 projection)
- Format: PNG files with transparent backgrounds & Original Aseprite files (.aseprite)
- Style: Retro 16-bit nature / dungeon environment

## Folder Structure:
- /Individual_Tiles/ -> Contains all separated PNG assets categorized by type (Ground, Vegetation, Props).
- /Spritesheet/ -> The combined spritesheet for quick importing.
- /Source_Files/ -> Original .aseprite files for editing and customization.
