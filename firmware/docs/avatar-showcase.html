FH1 avatars: style A

The FH1's avatar style (users.md): anime-inspired shaded pixel art, 3 tones per colour with a coloured outline, built from layers (body, clothes, hair, face, accessories) coloured from small palettes. Each view is shown at the three sizes the plan uses (full 96×128, face 32×32, mini 16×16), magnified, each drawn for its size. Every face is animated, the inline mini face too: a blink, a motion per expression and its effect. Below: random characters and the faces in FH1 screens. The firmware's renderer (components/fh1_avatar) is a C port of this page's renderer.
