# Vendored code

`peanut_gb.h`: Peanut-GB by Mahyar Koshkouei, MIT License (header of the file).
From https://github.com/deltabeard/Peanut-GB, branch `cgb` (Game Boy Color support), commit `33f053b9e70297ff0bab53da527c19126384d911`.
One change, marked "FH1 change": with `PEANUT_GB_RAM_POINTERS`, `wram` and `vram` are pointers the front end allocates (so they can go to internal RAM separately), instead of arrays inside `struct gb_s`.

`minigb_apu.c`, `minigb_apu.h`: the Game Boy's sound (APU), by Alex Baines and Mahyar Koshkouei, MIT
License (`minigb_apu.LICENSE`). From the same Peanut-GB commit, `examples/sdl2/minigb_apu/`. One change,
marked "FH1 change": the sample rate can be set from outside (32000 Hz, like the other consoles), and
`audio_registers()` gives the register memory. Its functions are compiled under other names (`apu_core_*`,
CMakeLists.txt): gb.c runs the APU on core 0 and answers the emulator's register accesses itself.

`gbc_palettes.h`: the Game Boy Color boot ROM's palettes for original Game Boy games (title checksums,
palette combinations, colours, the power-on button choices), generated by `tools/gbc_palettes.py` from
SameBoy's open boot ROM source (https://github.com/LIJI32/SameBoy, `BootROMs/cgb_boot.asm`), MIT/Expat
licence, Copyright (c) 2015-2026 Lior Halphon.
